## Findings and follow-up

### F1 — failed literature gate still returns success

**DERIVED**, [rge_2loop.py lines 282–283](https://github.com/irreducible-mystery/edge/blob/86191de74886d9ae817dcad303b5f08b0932bb66/01-datum/rge_2loop.py#L282).
The gate is printed but not included in `rc`. Setting `GATE_TARGET = 1.0`
in memory produces `FAIL` while `main(["--check"])` returns 0.
The real target passes; this finding concerns failure detection.

Recommended follow-up: include a failed gate in the exit status for the two-loop check.
Specify separately how the intentionally different one-loop mode should behave.

### F2 — last-digit agreement statement is too strong

**DERIVED**, [DATUM.md lines 93–94](https://github.com/irreducible-mystery/edge/blob/86191de74886d9ae817dcad303b5f08b0932bb66/01-datum/DATUM.md#L93).
The claim that all four other Planck-scale couplings agree to the last quoted digit
or within one unit fails for y_t: the run gives 0.38316819689439463
(0.3832 rounded), while the quoted reference is 0.3825.
The rounded difference is seven units of 0.0001.

Recommended follow-up: append a dated correction to DATUM.md and the two-loop ledger
follow-up, retaining the original record. State the actual y_t difference rather than
claiming one-unit agreement. This does not invalidate the λ gate.

### F3 — the regression check covers only part of the JSON

**DERIVED by code inspection**, [rge_2loop.py line 274](https://github.com/irreducible-mystery/edge/blob/86191de74886d9ae817dcad303b5f08b0932bb66/01-datum/rge_2loop.py#L274).
The compared keys are the two central-input dictionaries and three stability-edge values.
Monte Carlo results, finite-difference slopes, the running table, and the no-light-Yukawa
dictionary are not compared. They are computed during the run, but that is not a
regression assertion. A passing check does not certify the whole recorded JSON.

Recommended follow-up: compare the scientifically reported outputs with documented
numeric tolerances, or narrow the self-test documentation to its actual coverage.
