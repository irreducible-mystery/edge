# CLAUDE.md — read first in every session

**Why is the vacuum sitting on an edge?**

With the measured Higgs and top masses, the Standard Model's Higgs self-coupling runs to
approximately zero at the Planck scale, and its rate of change is approximately zero there
too. The measured universe sits within about one GeV of top mass from the boundary between
a stable and a metastable vacuum. Two frameworks predicted the Higgs mass from that
boundary before it was measured, and nothing else did. This repo takes that as a datum and
asks what explains it.

The owner set the question; sessions of several models work it. Start with the four files
in this order:

1. [`01-datum/DATUM.md`](01-datum/DATUM.md) — what is measured, what we have reproduced,
   and how far our own run is from the literature (one loop misses by 2×; two loops lands within 0.001).
2. [`QUESTIONS.md`](QUESTIONS.md) — the question split into the four it actually is, in the
   order they must be answered.
3. [`LEDGER.md`](LEDGER.md) — every claim with its tier. The tags are defined there.
4. [`ROLES.md`](ROLES.md) — co-creator, critic, breaker, visual, steward; what each does
   next.

## How to work here

- Branch per session, pull request into `main`, the owner merges. Sessions do not merge
  their own work. A review that *ran* the code outranks one that read it.
- Tier-tag every claim; the tags are in `LEDGER.md`. Say recall / inference / guess where
  it matters.
- The ledger only grows. Corrections go beside the original, dated.
- No flattery. Findings.
- No personally identifying information about anyone, anywhere.
- Add every new file to the index above in the same change.
- Findings go in the repo, not in chat: critiques as PR comments (plus an `AUDIT-*.md` if
  durable), built work as PRs, repo-level findings as issues, status lines in `STATUS.md`.
  Tell the owner what you posted and where; never hand the owner text to relay. See ROLES.md.

## Running

```sh
cd 01-datum
python3 rge_1loop.py          # prints the table, writes results.json
python3 rge_1loop.py --check  # exit 1 if results.json no longer reproduces
python3 rge_2loop.py          # two loops: prints the table, the gate, writes results_2loop.json
python3 rge_2loop.py --check  # exit 1 if results_2loop.json no longer reproduces or the 1-loop limit disagrees
python3 plot_lambda.py        # ../figures/lambda_running.png
```
Python 3 with numpy (and matplotlib for the figure). Nothing else.
